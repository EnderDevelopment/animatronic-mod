# Animatronic Mod

Adds FNaF-inspired animatronics to Minecraft with pathfinding and Faz Controll settings.

## Features

- Adds animatronics with pathfinding
- Faz Controll settings for movement, teleportation, and sounds
- FNaF door block
- Puppet Box item
- Animatronic Mode item
- Battery item
- Generator function
- GUI integration

## Requirements

- Minecraft 1.20.1
- Forge 1.20.1-47.1.0

## Installation

1. Download the mod from the releases page.
2. Place the mod file in your Minecraft mods folder.
3. Launch Minecraft with Forge.

## Usage

1. Craft or obtain the Animatronic Mode item.
2. Use the Animatronic Mode item to switch between Animatronic and Player modes.
3. Use the Puppet Box item to spawn animatronics.
4. Use the Battery item to power the generator.
5. Use the FNaF door block to create doors that can be opened and closed.

## Configuration

The mod can be configured by editing the `config/animatronicmodemod-common.toml` file.
